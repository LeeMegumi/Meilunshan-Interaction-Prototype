# 花蓮美崙山昆蟲館｜生態觀察牆互動原型

花蓮美崙山昆蟲館投影牆互動（短焦投影＋UST-10LX 雷達觸碰）的網頁版原型，內容與 Unity 正式版同步。

**線上檢視：** 開啟 GitHub Pages 網址即可操作，用滑鼠點擊代替觸碰牆面；按著滑鼠拖曳會出現滑過的小粒子。

## 內容
- 待機首頁 → 觀察牆（日景／夜景、20 種物種、觸碰反應與圖鑑卡）
- 找找看：60 秒內找出 6 種用保護色躲起來的生物，結算畫面
- 背景音樂、環境音與觸碰音效（第一次點擊畫面後開始播放，右下角可關閉聲音）

## 檔案
- `index.html`：整個原型（單一檔案）
- `audio/`：音效（mp3）
